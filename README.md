# Classificacao_arritmias_ECG
Classificação de arritmias cardíacas com base no sinal de Eletrocardiograma (ECG)

Dataset: MIT-BIH Arrythmia DataBase
-48 Pacientes (25 homens e 23 mulheres).
-Idade de 23 a 89 anos.
-48 trechos de sinal de 30 minutos.
-Taxa de amostragem = 360 amostras por segundo.
-Análise de dois ou mais cardiologistas que anotaram cada registro independentemente.
Aproximadamente 110000 anotações.
-Dois canais.
